# Hyper Quant Web3 Connect

Готовый проект Next.js для подключения кошельков.

## Инструкция по загрузке на Vercel с телефона:
1. Распакуйте ZIP-архив у себя на телефоне.
2. Зайдите на github.com -> Нажмите "+" -> "New repository" -> назвите `hyper-quant` -> нажмите "Create repository".
3. Нажмите "uploading an existing file" и загрузите файлы из архива в репозиторий.
4. Перейдите на vercel.com -> "Add New Project" -> Импортируйте репозиторий `hyper-quant` -> Нажмите "Deploy".
